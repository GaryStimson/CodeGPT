## Getting Started

1. **Download the Plugin**
2. **Configure Your API Key**
3. **Start Using the Features**

### Installation

The plugin is current available through an unoffical repository.

### Configuration

After successful installation, configure your API key. Navigate to the plugin's settings via **File |
Settings/Preferences | Tools | GizmoGPT**. Paste your API key into the field and click `Apply/OK`.
